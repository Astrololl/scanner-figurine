Mini guida GitHub Pages

  1. Scarica il file index.html.
  2. Accedi a github.com e apri github.com/new.
  3. Crea un repository chiamato scanner-figurine, seleziona Public e premi Create repository.
  4. Nel repository scegli Add file → Upload files, carica index.html e premi Commit changes.
  5. Apri Settings → Pages. In Build and deployment seleziona Deploy from a branch, branch main, cartella /(root), quindi Save.
  6. Dopo qualche minuto, premi Visit site. L'indirizzo sarà simile a https://TUONOME.github.io/scanner-figurine/.
  7. Aprilo in Chrome e consenti la fotocamera.

Il repository è pubblico, quindi il codice è visibile a tutti. I dati delle figurine non vengono caricati su GitHub: restano nel browser del telefono. Se cancelli i dati del browser o cambi dispositivo, usa Esporta/Importa backup.

Le immagini vengono elaborate nel browser e non caricate su un server. L'OCR può sbagliare: controlla i numeri. Serve Internet per scaricare il motore OCR la prima volta.
